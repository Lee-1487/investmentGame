# A에게 요청: '반토막' 능력 (코인 5개) 서버 처리

작성: D (UI). UI 쪽은 구현되어 있고, 실제 효과와 코인 차감은 서버(A 담당) 구현이 필요합니다.
D는 서버·규칙 코드(Flow, Rules, Network, Shared)를 수정하지 않았습니다.

## 기능 요약

- 비용: 코인 5개
- 대상: 자신을 제외한 다른 플레이어 1명
- 효과: 대상의 **이번 턴 최종 수익률을 절반**으로 만든다.
  - 수익이면 수익률 절반 (예: +20% → +10%)
  - 손실이면 손실률도 절반 (예: -20% → -10%)
- 사용 가능 시점: 같은 턴의 정보 탐색(INFO) ~ 지분 선택(SELECTION) ~ 실시간 매매(INVESTMENT)가 끝날 때까지
- 적용 시점: 그 턴의 정산(MARKET_REVEAL/RESULT 계산)
- 사용 횟수: 한 턴에 한 번 (UI 기준, 규칙상 변경 가능)

## 요청 1. 클라이언트 → 서버 명령

```json
{ "type": "USE_HALVE_RETURN", "targetPlayerId": "P3" }
```

검증 (실패 시 기존 오류 응답 형식으로 거절):

| 조건 | 오류 예시 |
|---|---|
| stockSystem 모드가 아님 | NOT_STOCK_MODE |
| 단계가 INFO/SELECTION/INVESTMENT가 아님, 또는 일시정지 | WRONG_PHASE |
| 코인 5개 미만 | NOT_ENOUGH_COINS |
| 대상이 없음 / 자기 자신 | INVALID_TARGET |
| 이번 턴에 이미 사용 | ALREADY_USED |

성공 시: 즉시 코인 5개 차감 → 이 턴의 반토막 대상 기록.

## 요청 2. 정산 반영

- 대상의 이번 턴 수익(손익 금액)을 절반으로 계산해 총자산·순위에 반영.
- 여러 명이 같은 대상에게 쓰는 경우(누적 1/4 인지, 한 번만 적용인지)는 A가 규칙으로 정해 주세요.

## 요청 3. 상태로 알려 줄 값 (UI가 표시에 사용)

- 내 PlayerView: `coins` (차감 반영) — 이미 있음
- 공개 상태 또는 내 PlayerView에 이번 턴 내가 건 대상: 예) `halveTargetPlayerId: "P3"`
- (선택) 결과 단계에서 반토막이 적용된 플레이어 목록: 예) `halvedPlayerIds: ["P3"]`

## UI 쪽 현재 동작 (D)

- 위치: 왼쪽 순위 열 맨 아래, '방 나가기' 위. 순위 칸과 같은 크기(84x86).
- 버튼을 누르면 눌린 상태 유지 → 상대 순위 칸 클릭으로 대상 선택. 바탕을 누르면 해제.
- 대상이 정해지면 그 플레이어 칸에 빨간 테두리(그 턴 동안).
- 연결 지점: `TabletView.HalveReturnRequested` (대상 playerId 전달). 서버 명령이 생기면 여기서 위 명령을 보내도록 연결합니다.
- 서버 구현 전까지는 표시만 되고, 코인 차감과 효과는 일어나지 않습니다.
