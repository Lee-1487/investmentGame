# 증강 — 현재 구현 요약

기준: 2026-11-10, 현재 일반·개발자 플레이 코드. 화면 설명보다 실제 적용 수치를 기준으로 정리했다.

## 1. 선택 방식

- **1·4턴 시작에 3개 후보 중 1개**를 선택한다. 선택한 증강은 게임이 끝날 때까지 유지되어 최대 2개를 보유한다.
- 후보는 시드·턴·플레이어별로 무작위 선정하며, 이미 보유한 증강은 제외한다. 증강별 별도 가중치는 없다.
- 현재 후보로 등장하는 증강은 **8종**이다. ‘유연한 투자자’는 여러 기업 동시 주문이 기본 규칙이 되어 후보에서 제외했다.
- 일반 모드는 **20초** 안에 선택하지 않으면 첫 후보를 자동 선택한다. 집중 투자자 자동 선택 시 대상은 AI다. 개발자 모드는 시간 제한이 없다.

## 2. 증강별 효과

| 증강 | 현재 적용 효과 |
|---|---|
| 내부 분석가 | 매 턴마다 정보 코인을 2개 더 받는다. |
| 바이오 연구원 | BIO 기업의 주식을 최대 15주까지 살 수 있다. |
| 우주 개척자 | SPACE 기업의 주식을 최대 15주까지 살 수 있다. |
| 복리의 마법 | BANK에 예금된 기간 * 0.5%의 추가 이자를 지급받는다. 최대 추가 이자는 15%이다. |
| 위험 분산 | 정산 시 **각 3주 이상인 기업이 3곳 이상**이면 기업별 음수 수익률을 **80%로 줄여 손실 20% 완화**한다. |
| 장기 투자의 힘 | 한 기업에 10일 이상 보유 시 얻는 수익율의 2배를 더 받는다. |
| 하락장 사냥꾼 | 직전 턴 **30일차 가격이 0일차보다 낮은 기업**의 이번 턴 **1~3일 정보**를 무료로 확인한다. |
| 집중 투자자 | 모든 기업에 대해 최대 12주까지 살 수 있다. |
