# 증강 — 현재 구현 요약

기준: 2026-11-16, 현재 일반·개발자 플레이 코드. 화면 설명보다 실제 적용 수치를 기준으로 정리했다.

## 1. 선택 방식

- **1·4턴 시작에 3개 후보 중 1개**를 선택한다. 선택한 증강은 게임이 끝날 때까지 유지되어 최대 2개를 보유한다.
- 후보는 시드·턴·플레이어별로 무작위 선정하며, 이미 보유한 증강은 제외한다. 증강별 별도 가중치는 없다.
- 현재 후보로 등장하는 증강은 **8종**이다. ‘유연한 투자자’는 여러 기업 동시 주문이 기본 규칙이 되어 후보에서 제외했다.
- 일반 모드는 **20초** 안에 선택하지 않으면 첫 후보를 자동 선택한다. 개발자 모드는 시간 제한이 없다.

## 2. 증강별 효과

| 증강 | 현재 적용 효과 |
|---|---|
| 내부 분석가 | 매 턴마다 정보 코인을 2개 더 받는다. |
| 바이오 연구원 | BIO 기업의 주식을 최대 15주까지 살 수 있다. |
| 우주 개척자 | SPACE 기업의 주식을 최대 15주까지 살 수 있다. |
| 복리의 마법 | BANK에 예금된 기간 * 0.5%의 추가 이자를 지급받는다. 최대 추가 이자는 15%이다. |
| 위험 분산 | 정산 시 **각 3주 이상인 기업이 3곳 이상**이면 기업별 음수 수익률을 **80%로 줄여 손실 20% 완화**한다. |
| 장기 투자의 힘 | 한 턴 안에서 한 기업을 **누적 10일 이상** 보유하면 해당 기업의 **양수 수익을 총 3배**로 받는다. 보유 구간이 끊겨도 날짜를 합산하며 손실은 증폭하지 않는다. |
| HIDDEN 손실 제어 | hidden 구간에서 발생한 손실율을 20%로 줄이는 대신 얻는 수익율이 50%로 줄어든다. |
| 집중 투자자 | 모든 기업에 대해 최대 12주까지 살 수 있다. |

## 3. 적용 시 알아둘 점

- BIO·SPACE의 15주 한도는 집중 투자자의 12주보다 우선한다. 전체 보유량 30주와 기업별 총 공급량 20주는 유지한다.
- 복리의 마법은 각 자산 슬롯이 실제 BANK에 예금된 일수에 하루 0.5%를 적용한다. 다른 기업에 투자한 기간에는 BANK 추가 이자가 붙지 않는다.
- 내부 분석가는 선택한 턴부터 실제 정보 코인을 2개 지급한다. 같은 턴의 재조회·요청 재전송으로 중복 지급하지 않는다.
- HIDDEN 손실 제어는 BANK를 제외한 기업을 실제 보유한 26~30일의 일별 변동에 적용한다. 음수 변동은 0.2배, 양수 변동은 0.5배로 합산한다. 예를 들어 -10%p는 -2%p, +10%p는 +5%p가 된다. 22~25일의 피뢰침·대 하락 전조는 원래 변동 그대로 정산한다. 차트와 다른 플레이어의 수익률은 바뀌지 않는다.
- 왼쪽 플레이어 아이콘을 클릭하면 해당 플레이어의 보유 증강 이름과 효과를 확인할 수 있다.
